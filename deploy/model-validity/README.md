# 模型有效性验收工具

只输出模型 ID、名称、状态和固定分类原因，不输出配置和凭据。全量明细见 `docs/13-模型有效性验收-20260909.md`。

- `inventory.py`：服务器本机读取生产模型配置；直接执行只输出安全字段。
- `audit.py`：隔离容器真实最小请求；`--retry` 只复查待验证项，会调用外部 API。
- `stage.py`：须有完整生产数据库复制授权；私有服务器快照、独立内网 MySQL/Redis/候选管理服务。数据库就绪后恢复，生产服务不变。
- `resume_stage.py`：仅用于首次恢复失败、测试数据库已初始化的恢复续跑，不可在已有测试管理容器时重复运行。
- `acceptance.py`：仅操作隔离数据库及候选 API；临时替换测试库管理员令牌并在结束时删除，不使用生产登录凭证。
- `test_model_validation.py`：探测策略单元测试。

构建产物、数据库备份、环境文件和令牌不得入库。候选镜像和完整备份保存在服务器 `/opt/aipet-model-validation-20260909` 私有目录。数据库容器仅内网可访问，采用 tmpfs，停止后不能视为持久备份。Docker 内网模式下宿主端口映射可能不生效，验收脚本使用测试容器内网 IP。
