# 服务用量与续费提醒

## 契约（先于实现）

仅小智管理台超级管理员。GET /models/usage 返回按服务及凭据分组的模型清单、启用/有效数量、查询支持情况、官方额度、重置时间及提醒；不返回密钥/完整配置。服务端最短60秒查询缓存，不自动请求付费推理来估算余额。

PUT /models/usage/reminder/{serviceKey} 保存人工套餐到期日 renewalDate（YYYY-MM-DD 或 null）。到期前7天提醒；官方剩余额度≤20%提示额度偏低，周期重置不当作套餐到期；无查询权限时不显示虚构余额。通知仅在页面内，不发送短信/邮件、不自动续费。

MiniMax 官方 Token Plan 接口为 https://www.minimaxi.com/v1/token_plan/remains（国际站对应 www.minimax.io）。来源：https://platform.minimaxi.com/docs/token-plan/faq.md。当前密钥已实际查询成功，general 返回周期/周剩余百分比，video另有计数；不将0总次数解释为0额度。

火山语音的 appid/access_token 只用于语音调用，未配置云账号 AK/SK 时不尝试账户账单签名接口。智谱等未核实当前模型密钥支持官方账户用量查询时标人工核对；Edge及本地/内置模块无本系统供应商账单。失效模板仍列出配置状态，不假报余额。

MiniMax-M3 官方标明原生多模态：https://platform.minimaxi.com/docs/guides/models-intro.md；M2.5 接受图片消息却未能识别，视觉检测改用随机左右色块校验，不能只凭返回文本判有效。

天气查询的默认共享和风凭据实测401。移除内置共享凭据回退，区分未配置、鉴权失败、限额、网络失败与真正城市不存在，不再把供应商错误说成地名错误。

智谱当前密钥实测 `GET https://open.bigmodel.cn/api/monitor/usage/quota/limit` 返回 HTTP 200、业务 code 500、success false，无用量数据。因此界面保持人工核对，不能报余额为0或说模型API失效。和风默认凭据改用 X-QW-Api-Key 请求头复核同样401，不是只因旧查询参数写法。

进一步核对了当前智能体唯一一份天气插件配置：其独立配置凭据实测同样返回401。因此已证实当前调用的鉴权失败，不只是上游默认值失效。修复请求使用官方 API Key 请求头，避免密钥出现在URL中。

## 声音复刻2.0契约

依据用户提供的音色训练HTTP文档2534906及音色查询HTTP文档2535742：训练 `POST https://openspeech.bytedance.com/api/v3/tts/voice_clone`；只读状态查询 `POST https://openspeech.bytedance.com/api/v3/tts/get_voice`。新控制台用 X-Api-Key；旧控制台按文档2534847使用 App-Key/Access-Key/Resource-Id。

本地原 `/voiceClone/cloneAudio` 增加 apiVersion=v3 分支，旧客户端默认保留原接口。新增 POST /voiceClone/{id}/status，仅资源所属用户或超级管理员查询；训练仍仅资源所属用户。返回本地状态、剩余训练次数、查询时间及一小时内有效的官方试听URL，不返回密钥或原始录音。支持已有S_音色及合规后付费自定义ID；上传格式沿用页面转换后的WAV，最大10MB。

训练必须页面确认，服务端防止同一资源并发训练；网络超时保留待确认状态，只读刷新后再决定重试。取消前端训练自动重试。不会自动训练、试听、正式合成或续费；自定义后付费音色首次正式合成可能产生槽位费，页面明确提示。训练状态2/4视为可用，其余状态不能标成功。

续费提醒增加声音复刻资源行，显示最近主动查询所得的剩余训练次数；训练次数不是合成字符余额。get_voice不提供到期时间，不据此推算；到期信息仍由控制台/人工填写。自动获取官方到期时间需要云账户AK/SK调用ListMegaTTSTrainStatus，当前未配置，不自动操作续费接口。
