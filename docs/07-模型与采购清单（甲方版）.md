## 一、模型服务需求总览（对标小智官方云服务）

设备一次对话的完整链路：`唤醒词（板载）→ 语音识别(ASR) → 大模型对话(LLM) → 语音合成(TTS)`，外加视觉理解（VLLM，选配）与记忆（Memory）。

### 1.0 对标基准：小智官方云服务（xiaozhi.me）的实际水准

小智官方为设备提供免费托管云服务，其公开可查的实际配置是本项目体验对标的基准：

| 模块 | 小智官方云服务现状 |
|------|------|
| 服务模式 | **免费托管**（官方明示"无法保证永久免费"），数据在官方侧 |
| LLM 对话 | **阿里百炼 Qwen 系列实时模型**（个人用户注册即可免费使用） |
| TTS 语音合成 | **火山引擎大模型语音**（"湾湾小何"等招牌音色，官方统一采购） |
| ASR 语音识别 | 商业流式 ASR（流式链路，官方称流式配置比入门方案快约 2.5 秒） |
| 记忆 | 本地短期记忆（总结式），无跨设备业务记忆 |
| 人设 | 官方预置角色模板（星仔、湾湾小何等），控制台手工编辑 |

**我们自建的动机**：数据自主（对话/记忆归自己）、人设与记忆业务化（星座×MBTI 人设编译、长期记忆、App 联动）、不被官方免费策略变动卡脖子。代价是自行承担模型 API 成本（本清单即为此估算）。

### 1.1 我们当前配置 vs 官方云服务（结论先行）

| 模块 | 官方云用什么 | 我们当前 | 判定 |
|------|----------|----------|------|
| 唤醒/VAD | 板载本地 | 板载本地（相同） | ✅ 一致 |
| ASR | 商业流式 | **豆包流式语音识别 2.0**（试用 20h） | ✅ 同级 |
| TTS | 火山·湾湾小何 | **火山·湾湾小何**（同款音色同家服务） | ✅ **完全同款** |
| LLM | **阿里 Qwen（百炼）** | GLM-4.5-Flash（智谱免费） | ⚠️ **唯一差距**：可用但响应与质量不及 Qwen 实时模型 |
| 意图/工具 | function_call | function_call（相同） | ✅ 一致 |
| 记忆 | 本地短期记忆 | 业务侧长期记忆（V0.2 上线中） | ⭐ 超越官方 |
| 人设 | 控制台手工模板 | PersonaCompiler 动态编译（V0.2 上线中） | ⭐ 超越官方 |

**总体判断：TTS 已与官方云完全同款，ASR 同级，唯一差距是 LLM——官方云用 Qwen，我们用免费 GLM 过渡。LLM 升级后即全面对齐官方云体验，且记忆/人设两项形成差异化超越。**

### 1.2 LLM 升级方案（补齐官方流式档的最后一块）

> 场景特征：短轮次闲聊 + 固定人设 prompt（可缓存）+ function calling（控制眨眼等硬件工具，刚需）。
> 单设备用量：每天 100 轮 ≈ 10~20 万 token ≈ **每月 300~600 万 token**。

| DeepSeek V4-Flash | 1 / 2（缓存命中 0.02） | ≈2~6 元 | 人设 prompt 缓存命中后成本最低 |

- 火山新客福利：**¥19.9 购 1000 万 token 包**（约标准价 4 折），单设备能用 2~3 个月

#### C. 结论与采购建议

1. **样机调试期（现在）**：GLM-4.5-Flash 免费档，零采购
2. **内测演示前（对齐官方云体验）**，二选一：
   - **严格对标派：阿里百炼 qwen-flash**——官方云服务同系 Qwen 模型，体验上最接近"官方云复刻"；百炼新客有免费额度可先试
   - **运维最优派：豆包 Seed 1.6 Flash + ¥19.9 新客 token 包**——与 ASR/TTS 同火山账号同账单、价格全场最低、function calling 稳定性是小智社区验证最好的；体验与 Qwen 同档
   - 建议：**先开百炼免费额度试 qwen-flash（严格对标），同时备 ¥19.9 豆包 token 包（运维兜底）**，两者都只是一条配置切换的成本
3. **产品差异化验证（可选并行）**：一台设备挂 **MiniMax M2.7**（先用注册赠送的免费额度）做"宠物感"A/B；若明显更好，再评估 Token Plan Plus（¥49/月，顺带把 TTS 也换成 MiniMax Speech，一份订阅覆盖两家之事）
4. **跑量后（数十台）**：切 DeepSeek V4-Flash（缓存命中价 0.02 元/百万，人设场景成本地板）或续豆包阶梯价，届时出精算表

### 1.3 ASR 费用说明（火山引擎）

- 试用：20 小时识别时长、3 路并发。样机期足够（每天 200 轮对话约耗 0.5 小时）
- 试用到期后两条路：
  - 购买时长包（约 1~2 元/小时量级，以官网为准）
  - 或切回本地 FunASR（**免费**，官方入门档同款，已部署为兜底，代价是延迟回落到入门档水平）

### 1.4 TTS 费用说明（火山引擎）

- 当前音色："湾湾小何"（台湾女声，贴合人设；**与小智官方控制台同源音色**）
- 计费：后付费约 4.5 元/万字；新客字数包 **¥22.5 / 10 万字**（原价 45 元，五折）
  - 10 万字 ≈ 单设备重度使用 2 周 / 正常使用 1~2 个月
- 采购建议：样机期买 1 个新客字数包（¥22.5）即可
- 音色升级路径（可选，后期）：
  - 火山·声音复刻（克隆专属音色）：新客 ¥110.4/音色 + 存储费 ¥0.8/音色/月
  - MiniMax·声音复刻：¥9.9/音色（更便宜的克隆路径，届时对比质量后二选一）

### 1.5 备用与兜底（已就绪，免费）

- ASR 兜底：本地 FunASR（官方入门档同款，已部署）
- TTS 兜底：EdgeTTS（官方入门档同款，已配置台湾腔音色）
- LLM 兜底：GLM 免费档长期可用（限速）
- **任何一家云服务故障或欠费，设备都不会"变哑"，只是体验从官方流式档回落到入门档**

### 2.2 近期需要采购/办理

| 项目 | 预估费用 | 紧迫度 | 说明 |
|------|----------|--------|------|
| **域名** | 约 30~80 元/年 | **高** | 正式上线的公网入口，后续 HTTPS/WSS/备案都依赖它 |
| **ICP 备案** | 免费（耗时约 2~3 周） | **高** | 国内服务器+域名对外提供服务必须备案，建议尽早启动 |
| TLS 证书 | **免费**（Let's Encrypt） | 随域名 | 设备通信加密（WSS/HTTPS） |
| 火山 TTS 字数包 | ¥22.5（新客 10 万字） | 中 | 见 1.3 |
| 火山 ASR 时长包 | 试用 20h 到期后再定（数十元级） | 低 | 见 1.1 |
| LLM token 包（豆包新客 1000 万 token） | ¥19.9 | 中 | 对齐官方流式档的最后一块，见 1.2；比"充 100 元按量"更划算 |

### 2.3 运营期可选

| 项目 | 预估费用 | 说明 |
|------|----------|------|
| 阿里云 OSS 对象存储 | 几元~几十元/月 | 附件、数据库备份归档（母文档既定方案） |
| ECS 快照备份 | 几元/月 | 数据安全保障 |
| 声音复刻（专属宠物音色） | ¥9.9~110/音色 | 产品差异化选项，见 1.3 |
| 云资源升配 | 视设备量 | 设备超 20~30 台或上 Agent 重任务时再评估 |

### 2.4 明确不采购（现阶段）

- GPU 服务器 / 本地大模型自托管（成本高、运维重，触发条件未满足）
- K8s、Kafka、Elasticsearch 等重型中间件（单机 Docker Compose 足够）
- 付费监控/日志服务（阿里云免费云监控 + 应用日志即可）
