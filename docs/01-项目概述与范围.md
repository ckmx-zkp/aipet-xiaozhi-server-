# 01 — 项目概述与范围

## 一句话

提供与 ESP32 小智固件兼容的自建会话后台，使人设 pack、设备 MCP、旁路历史能在**自控云**上跑通。

## 目标（Must）

- [ ] 基于开源 `xiaozhi-esp32-server` 部署全模块 + 全 API 模式  
- [ ] 设备通过自定义 OTA URL 激活并完成 MQTT/WS 会话  
- [ ] 会话可加载业务侧下发的 system Prompt 片段（persona_pack）  
- [ ] 设备 MCP（含 `self.eye.*`）路由可用  
- [ ] 转写文本可旁路推给业务后端（Webhook/队列）  
- [ ] 可配置挂载远程 Memory MCP（业务仓提供）  

## 非目标（Won't / 本期）

- 自研全套 ASR/TTS 模型托管（用外部 API）  
- 在本仓实现星座 KB 与记忆审核 UI  
- 真宠巡航、大 IP 卡牌  
- 浏览器 Agent 进实时语音路径  

## 版本对齐（产品）

| 产品版本 | 本仓交付 |
|----------|----------|
| V0.1 | 自建可聊 + 固定/薄人设 Prompt |
| V0.2 | 动态加载 persona_pack + 旁路历史 + Memory MCP |
| V0.3+ | 外设状态观测钩子、更稳的 MCP 审计日志（可选） |
