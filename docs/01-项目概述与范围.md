# 01 — 项目概述与范围

## 一句话

提供与 ESP32 小智固件兼容的自建会话后台，使人设 pack、设备 MCP、旁路历史能在**自控云**上跑通。

## 目标（Must）

- [x] 基于开源 `xiaozhi-esp32-server` v0.9.6 部署全模块 + API 模式
- [x] 设备通过自定义 OTA URL 激活并完成 WebSocket 会话
- [x] 会话加载业务侧 `persona_pack`，并按默认 300 秒刷新
- [x] 设备 MCP（当前 `self_eye_*` 五工具）原样路由可用
- [x] 转写、设备首见、会话结束和外设状态已实现业务后端旁路（待真机落库验收）
- [x] 可配置挂载远程 Memory MCP（b10：受控 Docker 内网 streamable HTTP，三工具白名单；待真机调用验收）
- [x] 将 backend Context Provider 短摘要合并入最终 Prompt（b8 已上线，2026-08-16 容器级验收通过，待真机验收）

## 非目标（Won't / 本期）

- 自研全套 ASR/TTS 模型托管（用外部 API）  
- 在本仓实现星座 KB 与记忆审核 UI  
- 真宠巡航、大 IP 卡牌  
- 浏览器 Agent 进实时语音路径  

## 版本对齐（产品）

| 产品版本 | 本仓交付 |
|----------|----------|
| V0.1 | 自建可聊 + 固定/薄人设 Prompt |
| V0.2 | 动态 `persona_pack`、固定基础行为层、旁路历史/外设（Memory MCP 依赖后端） |
| V0.3+ | Context Provider、Memory MCP、外设观测完善、更稳的 MCP 审计日志 |
