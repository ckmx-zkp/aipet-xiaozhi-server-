# 05 — 与业务后端集成接口

基址约定：`BUSINESS_API=https://<内网或同机>/api`（仅内网或 mTLS）。

## 本仓 → 业务（出站）

| 时机 | 方法 | 说明 |
|------|------|------|
| 会话开始 | `GET /internal/devices/{device_id}/persona_pack` | 拉人设包 |
| 用户/助手消息落定 | `POST /internal/chat/events` | 旁路脱敏文本（或由业务侧再脱敏） |
| MCP 结果（可选） | `POST /internal/peripheral/events` | 更新外设快照 |
| 会话结束（可选） | `POST /internal/chat/sessions/{id}/end` | 触发摘要入队 |

### `chat/events` 最小 payload

```json
{
  "device_id": "...",
  "session_id": "...",
  "role": "user|assistant|tool",
  "content": "...",
  "ts": "ISO-8601"
}
```

## 业务 → 本仓（入站，可选）

| 用途 | 说明 |
|------|------|
| 刷新智能体缓存 | 人设变更后 bump 缓存 key |
| 智控台深链 | Admin 外链，不经业务代理密钥 |

## Memory MCP

- 业务仓部署 `memory-mcp`。  
- 本仓按上游方式配置「远程 MCP」指向该地址。  
- 工具：记住/查询/忘记（以业务文档为准）；检索可带 `retrieval_hints`。  

## 失败策略

| 失败 | 策略 |
|------|------|
| 拉 pack 失败 | 用缓存；无缓存用安全默认；会话仍继续 |
| 旁路写入失败 | 本地重试队列，**不阻断** TTS |
| Memory MCP 失败 | 对话继续，仅无长期记忆 |

## 验收

- [ ] 10 轮对话后业务库可见消息（脱敏）  
- [ ] Memory 工具可召回一条手动记忆  
- [ ] 业务宕机时设备仍能完成基础闲聊
