# 模型有效性检查契约

模型管理属于小智管理 API，不改变 AI Pet 业务 API 或 MCP 契约。

- 模型列表/详情增加 validityStatus（valid/invalid/unknown，默认 unknown）、validityReason、validityCheckedAt。
- POST /models/{id}/validate：仅超级管理员；使用数据库当前配置，在语音容器执行最小能力探测。返回状态和原因，不返回密钥、供应商响应原文或用户内容。不自动启用、不自动重试收费请求。
- Python POST /internal/models/validate：仅 server.secret 共享密钥认证，固定结构 modelType/config；不接受代码或命令。独立子进程限时，限制并发；失败消息只使用固定分类。
- 有效必须有真实能力响应；缺失凭据/占位配置/鉴权拒绝/额度不足/模型不存在为 invalid；超时、网络异常或尚无验证适配器为 unknown，不能谎报密钥过期。
- 无效或未验证配置不能新启用或设为默认；新增默认禁用；配置内容或类型改变后清除旧验证状态并禁用，取消原默认标记。仅改名称/备注不清除有效性。禁用始终允许。
- 检查结果仅在配置未变时写回；invalid/unknown 取消启用及默认，不自动更改智能体所选模型。检查日期只是最近一次证据，不保证永久有效。
- 内置 VAD/关闭记忆/意图等不按 API 密钥检查，分别验证本地推理或模块加载。外部依赖尚未验证时不能标有效。
- 迁移现有配置时不直接停用，完成探测后逐项应用结果。备份 MySQL 与镜像；前端和 Java 管理 API 成套部署。

验证范围：LLM 最小文本回复；VLLM 最小图片识别；TTS 获取实际音频；火山 ASR 上传合成测试语音并收到识别结果；本地模型执行小样本。测试不调用声音复刻训练、不使用用户录音。
