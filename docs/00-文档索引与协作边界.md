# 00 — 文档索引与协作边界

## 三仓一固件

| 目录 | 角色 |
|------|------|
| `Home_Work/xiaozhi-server`（本仓） | 小智兼容：OTA、会话、MCP 路由、智能体运行时 |
| `Home_Work/ai-pet-backend` | 业务真源：人设 KB、记忆、历史、API、Worker |
| `Home_Work/ai-pet-admin` | Web 管理台 |
| `Home_Work/ESP32_XIAOZHI/xiaozhi-esp32` | 设备固件（身体/MCP 工具） |

产品级 PRD / 选型仍在 `ESP32_XIAOZHI/*.md`，本目录只放**可开发执行**的拆分文档。

## 依赖顺序

1. 本仓可独立拉起 → 设备改 `ota_url` 能对话  
2. `ai-pet-backend` 提供 pack / 旁路入库 API  
3. 本仓集成：会话前拉 pack；会话中旁路转写；挂 Memory MCP  
4. `ai-pet-admin` 调业务 API；智控台链到本仓管理 UI  

## 硬边界

| 可以进本仓 | 禁止进本仓 |
|------------|------------|
| ASR/LLM/TTS 编排（外部 API） | 星座知识库条目运营 |
| 设备 MCP 下发 | 记忆 CRUD 真源表 |
| OTA/激活 | 用户业务账号体系（可镜像设备在线） |
| 智能体 Prompt **运行时加载** | PersonaCompiler 实现（调用业务 API 即可） |
