## 2. 有效配置文件（脱敏基线）

### 2.1 `/opt/xiaozhi-server/data/.config.yaml`（server 容器挂载）

```yaml
server:
  ip: 0.0.0.0
  port: 8000
  http_port: 8003
  vision_explain: http://39.107.143.71:8003/mcp/vision/explain
  auth_key: <SERVER_SECRET>          # ⚠ 必须等于 server.secret，见 §3 坑 2

  url: http://xiaozhi-esp32-server-web:8002/xiaozhi
  secret: <SERVER_SECRET>            # 位置：智控台→参数管理→server.secret；或 MySQL sys_params

```

### 2.2 MySQL `sys_params` 关键参数（智控台"参数管理"可见）

| param_code | 基线值 | 说明 |
|------------|--------|------|
| `server.secret` | <随机 36 位> | manager↔server 共享密钥，同时用作 WS token 签名钥 |
| `server.fronted_url` | `http://39.107.143.71:8002` | OTA 激活提示里展示给用户的地址 |
| `server.ota` | `http://39.107.143.71:8002/xiaozhi/ota/` | 固件 OTA 入口（固件 `CONFIG_OTA_URL` 指这里） |
| `server.websocket` | `ws://39.107.143.71:8000/xiaozhi/v1/` | OTA 下发给设备的 WS 地址 |
| `server.auth.enabled` | `true` | 设备 WS 鉴权开关（HMAC token） |

## 3. 已踩过的三个坑（新会话必读）

1. **OTA 下发占位域名**：全新部署时 `server.fronted_url` 默认 `http://xiaozhi.server.com`、`server.websocket` 为空（manager 用占位兜底）——设备拿到的 WS 地址无法解析。**必须**按 §2.2 改成公网地址。
2. **`server.auth_key` 必须等于 `server.secret`**：manager-api 用 `server.secret` 签设备 WS token，Python 端用 `config.server.auth_key` 验签；上游模板不含 auth_key（默认为空串），不补齐则设备激活后也连不上 WS。
3. **改参数/模型配置后必须清缓存**：manager-api 把参数和模型配置缓存在 Redis，直连 MySQL 改值后需 `docker exec xiaozhi-esp32-server-redis redis-cli FLUSHALL`（智控台 UI 改则自动失效）。当前无在线会话，FLUSHALL 安全；有用户后改用定向删 key。

## 5. 常用运维命令

```bash
ssh aliyun-aipet
cd /opt/xiaozhi-server
docker compose -f docker-compose_all.yml up -d        # 启动/重建
docker compose -f docker-compose_all.yml restart xiaozhi-esp32-server   # 改 .config.yaml 后重启
docker logs -f xiaozhi-esp32-server                   # 语音服务日志
docker exec xiaozhi-esp32-server-redis redis-cli FLUSHALL   # 清参数缓存（见 §3.3）
# MySQL 密码：grep MYSQL_ROOT_PASSWORD docker-compose_all.yml
```

### 自建镜像重建流程（代码二开后）

```bash
# 本地：提交推送 → 服务器：
cd /opt/xiaozhi-server/repo && git pull
docker pull ghcr.nju.edu.cn/xinnan-tech/xiaozhi-esp32-server:server-base   # 基础镜像（已 tag 为 ghcr.io 同名）
docker build -f xiaozhi-esp32-server/Dockerfile-server -t xiaozhi-aipet-server:v0.9.6-b<N> xiaozhi-esp32-server
# 改 compose 里 server 镜像 tag → docker compose -f docker-compose_all.yml up -d
```
