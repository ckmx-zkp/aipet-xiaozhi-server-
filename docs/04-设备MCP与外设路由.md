# 04 — 设备 MCP 与外设路由

## 角色

| 角色 | 谁 |
|------|-----|
| MCP Server | ESP32 固件 |
| MCP Client / 路由 | 本仓（小智服务在会话中 `tools/list` / `tools/call`） |

## 已验证工具（固件）

- `self.eye.look` / `blink` / `close` / `open` / `set_emotion`  
- 公共：音量、设备状态等（上游 + 板级）  

## 本仓职责

1. 会话内发现并调用设备工具（上游已具备则回归即可）。  
2. **不要**在本仓实现星座计算。  
3. 可选：将会话级 `default_emotion` 在开场自动 `tools/call`。  
4. 可选：抽样 MCP 调用日志 → 推业务旁路（P2）。  

## 隔离

- 实时 MCP 与语音同属高优先级面。  
- Agent/浏览器任务禁止与语音抢同一无限额进程（见服务器需求 Docker 限额）。  

## 后续固件工具（本仓仅路由）

| 阶段 | 工具方向 |
|------|----------|
| V0.3 | 灯带 / 舵机 / 状态回读增强 |
| V1.0+ | 行为控制器相关工具（若固件暴露） |
